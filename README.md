# Bank Management System

A simple Bank Management System developed using Python.

## Features

- Create a New Bank Account
- Check Account Balance
- Deposit Money
- Withdraw Money
- View Account Details
- Exit the Application
- Validate Account Numbers
- Check Available Balance before Withdrawal

## Technologies Used

- Python 3
- Python Dictionaries
- Functions
- Conditional Statements
- Loops

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python bank_management.py
```

## Project Objective

The objective of this project is to manage basic banking operations through a simple menu-based Python application.
